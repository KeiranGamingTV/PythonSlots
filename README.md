Ever wanted to experience a simple slot machine from home, but don't want to spend any money? Use your computer's terminal!

# Features
- Different betting amounts
- Win Streak
- Win Multiplier
- Saved Stats
- XP and Level System
- Daily Challenges

# Usage
Download repo as a .ZIP file. (Click $$\color{Green}{\textbf{<> Code}}$$ -> Download ZIP)
Extract to a folder named PythonSlots (or something else you'd like).
Open `main.py` and start playing! Previous game stats will be saved to the included `slots_data.json` file.
